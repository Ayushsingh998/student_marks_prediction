# Student Marks Prediction

This project contains a full-stack student marks prediction app with:

- FastAPI backend
- Machine learning model training pipeline
- LLM-based advice endpoint
- Static frontend pages for form and dashboard

## Structure

- backend/
- frontend/

## Run backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Run frontend

Open `frontend/index.html` in a browser.
